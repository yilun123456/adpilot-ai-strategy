# AdPilot 广告投放策略助手

AdPilot 是一个面向广告运营与媒介策略团队的 Campaign Brief 工作台。它强调“可追溯”，不把演示数字包装成真实预测。

## 已实现

- 解析 Brief 中的品牌、目标、人群、市场、预算和周期
- 使用 Cloudflare D1 持久化真实历史案例
- 从 CSV / JSON 批量导入、检索和删除案例
- 强制每个真实案例填写数据来源
- 按关键词重合与预算接近度计算可解释匹配度
- 在策略页面和 Word 文档中展示引用来源
- 导出可编辑 Word，或通过打印导出 PDF
- 没有真实数据时明确显示为演示模式

## 案例导入字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `brand` | 是 | 品牌名，可使用脱敏名称 |
| `title` | 是 | 案例或项目名称 |
| `source` | 是 | 内部复盘编号、文档路径或可访问 URL |
| `industry` | 否 | 行业 |
| `objective` | 否 | 核心目标 |
| `audience` | 否 | 目标人群 |
| `budget` | 否 | 预算，单位万元 |
| `channels` | 否 | 渠道及占比 |
| `period` | 否 | 投放周期 |
| `result_metric` | 否 | 真实结果指标名称 |
| `result_value` | 否 | 真实指标结果 |
| `summary` | 否 | 策略与复盘摘要 |

单次最多导入 100 条。建议先对客户名、联系人和敏感金额做脱敏。

## 本地开发

```bash
pnpm install
pnpm dev
```

项目使用 Vinext、React、Cloudflare D1 和 Sites。D1 逻辑绑定名为 `DB`，迁移文件位于 `drizzle/`。

## 当前边界

渠道预算仍由透明规则生成，成效数字属于待校准假设。即使接入真实案例，也不能将历史结果直接当作本次项目承诺。正式使用时应由策略负责人复核媒体价格、归因口径和 KPI。

后续接入大模型时，应在服务端使用密钥，以结构化输出生成方案，并继续保留案例来源、规则校验和人工确认环节。
